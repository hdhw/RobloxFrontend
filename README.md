## About

**RobloxFrontend** is an archival project dedicated to preserving and documenting the evolution of Roblox's frontend throughout its history.

Spanning from the earliest days of Roblox in **2005** to the modern platform in **2027**, this repository brings together frontend files and resources from over two decades of development.

Whether you're interested in historical website designs, classic interfaces, or the evolution of Roblox's frontend, this collection aims to make that history accessible.

## What's inside

Every year has its own folder containing a complete, self-contained page of that year's research — a chat export with every attachment that was posted in it:

```
2005/
├── 2005.html                  <- the year's page (chat export, fully offline)
└── 2005.html_Files/           <- every asset posted in that page
    ├── screenshots, photos, videos
    ├── .7z / .zip caches and site snapshots
    ├── .css / .js / .htm page captures
    └── fonts, emoji, avatars
2006/ ... 2027/
aprilfools2012/    ask/    cache/    march172009everyoneadminday/
misc/              recreations/
```

**2,600+ files** — every screenshot, video, cached site archive, stylesheet and page capture referenced by the year pages is included, so each `<year>.html` opens fully offline with nothing missing.

## How to use it

Open any year's page in a browser — everything it references sits next to it, so it works fully offline:

```bash
# from the repo root, e.g.
xdg-open 2009/2009.html        # Linux
start    2009\2009.html        # Windows
```

**Search tip:** each page is plain HTML — hit Ctrl+F and search things like `2009M`, `December 2009` or `Authed` to jump straight to what you're looking for.

## Source

The collection originates from the **ROBLOX Frontend Research** community, with the public mirror at [archive.miikart.co](https://archive.miikart.co/). All year pages and attachments are preserved as captured.
